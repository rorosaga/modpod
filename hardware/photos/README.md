# Your build photos

Add your own photos here when the hardware session starts. Suggested names:

- `01-before-front.jpg` and `02-before-back.jpg`
- `03-parts-and-labels.jpg` (card SKU and battery dimensions)
- `04-ribbon-before-removal.jpg`
- `05-quad-usd1.jpg`
- `06-battery-dry-fit.jpg`
- `07-before-closing.jpg`
- `08-finished.jpg`

Record anything private in `private/`, which Git ignores. Do not include serial numbers, addresses, or order details in public photos. Replace the remote product-photo URL in `hardware/parts.json` with your own relative photo path when ready.

The current handbook embeds credited product images from the original sellers. They have not been downloaded or copied into the repository.
